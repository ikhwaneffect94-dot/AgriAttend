AgriAttend v1.6.8 test report

Included source changes:
- Added a Verval modal with province and regency/city selectors inside AgriAttend.
- The province list uses the Indonesian province code list; regency/city options load dynamically and have fallback lists for Kalimantan Tengah and Kalimantan Selatan.
- The native bridge launches a hidden, 1x1 WebView runtime; no official SIMKOPDES page is visually displayed.
- The runtime attempts province selection, regency/city selection, automatic passcode fill, official submit, and table extraction.
- Parsed table fields are returned to the AgriAttend Verval callback for cooperative-name matching.
- Failure diagnostics report safe DOM metadata but do not include input values.
- The shared passcode is compiled into the APK and is not logged or rendered in the UI.
- CAPTCHA, login, and denied access are not bypassed.
- Android versionName 1.6.8, versionCode 27.
