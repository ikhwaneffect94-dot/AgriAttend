AgriAttend v1.6.2 test report

Passed:
- JavaScript syntax check: app.js and sw.js (Node.js)
- AndroidManifest.xml XML parse
- HTML IDs are unique (168 IDs checked)
- Required Verval UI elements are present (8 elements checked)
- GitHub Actions workflow parses as one root workflow with keys: name, on, permissions, jobs
- Version metadata is consistent: versionName 1.6.2, versionCode 21
- SIMKOPDES direct client contains the four intended API paths:
  * /cooperative-assets/get-all
  * /statistics/asset-verification-validation
  * /statistics/national/phase-2
  * /cooperative-assets/by-regional-facilitator-id/{fid}
- SIMKOPDES direct client does not create/use WebView and the shared portal passcode is not embedded
- SimkopdesPublicApi.java syntax/type check completed with minimal Android Base64 and org.json interface stubs (not a substitute for the Android Gradle build)

Included integration:
- Fetch public cooperative asset records and filter by selected province/district, assignment-derived subdistrict hint, and normalized Kopdes name.
- Consolidate multiple asset records for the same cooperative into one Kopdes result and expose an asset count.
- Fetch aggregate verification/construction statistics per province from /statistics/asset-verification-validation.
- Fetch phase-two aggregate province x Satgas data from /statistics/national/phase-2.
- Validate the frontend-bundle AES-CBC/PKCS7 parameter pair first against the smallest available statistics response, with dynamic bundle-discovery fallback, before fetching the large public asset tree.
- Prefill Verval province/district from AgriConnect placement; retain the last confirmed selection, keep manual editing available, and bound the region lookup to 12 seconds.
- Provide Kalimantan Tengah and Kalimantan Selatan fallback district lists when the public region-list service is unavailable.
- Preserve per-endpoint failure notes so one optional statistics endpoint can fail without hiding the other successfully fetched data.
- Optional account-scoped facilitator asset lookup uses the user's own authorized Bearer token and regional-facilitator ID, stored with Android Keystore. The shared Verval page passcode is not an API token.

Not verified in this environment:
- Live SIMKOPDES HTTP access, current JavaScript cipher bundle, API payload decryption, or lookup against a real assignment. The live SIMKOPDES server is not reachable from this build environment.
- Full live SIMKOPDES lookup and matching to a real assignment. Android Gradle build and APK assembly are verified by the GitHub Actions workflow for this branch; live API behavior still requires an authorized device/network.
- Protected-page Batch 1-4 and non-priority fields are not exposed by the documented public API responses used here. They are not inferred from asset status or aggregate construction statistics.

The main app shell keeps its WebView only to render the bundled local AgriAttend UI. SIMKOPDES retrieval itself is performed by native HTTPS API calls and does not open the SIMKOPDES website in any WebView.
