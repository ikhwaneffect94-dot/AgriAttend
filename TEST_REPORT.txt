AgriAttend v1.7.1 test report

Changes:
- Fixed the duplicated Verval JavaScript runner wrapper; the injected page script now contains one async runner.
- Changed the hidden WebView from a 1×1 invisible viewport to a full-size, transparent, non-interactive viewport so the portal uses normal responsive layout.
- Verval now starts from province/regency/city and cooperative assignment in the AgriConnect placement card when all are available.
- Retained manual region selection only when placement region information is incomplete.
- On a successful native response, the PWA stores the matched record and explicitly calls renderVervalPage() so the card displays the new data.
- Error, not-found, and ambiguous responses update the card state; the action button is restored in the callback finally block.
- Added a 70-second PWA watchdog to clear a stuck checking state if the native callback never returns.
- Native WebView operation has a 60-second timeout with a visible error message.
- Batch 1–4 and Non Prioritas category scanning remains enabled, with up to six pages per detected category.
- The action card reports incomplete coverage when not all expected categories/page checks are confirmed.
- Android versionName 1.7.1, versionCode 30.

Automated checks:
- node --check app/src/main/assets/app.js
- Extract the Java text-block Verval automation script and run node --check against the generated JavaScript.
- Verify the automation runner appears exactly once.
- Verify the transparent full-viewport WebView configuration.
- Verify Verval result rendering, error-state handling, and watchdog.
- Parse AndroidManifest.xml and confirm version metadata.
- Run Android Gradle build, verify APK output, and upload artifact.

Not yet verified:

- Whether the target KDKMP record is beyond page six in any category.
- Successful end-to-end match for KDKMP Teluk Palinget.
