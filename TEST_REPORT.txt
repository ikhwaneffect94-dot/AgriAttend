AgriAttend v1.6.7 test report

Source-level changes:
- Replaced the active Verval button flow with the official SIMKOPDES Verval route embedded in a dedicated Android WebView activity.
- Added the route: https://simkopdes.go.id/pers/asset/verval?batch_verification=1%2C2%2C3%2C4
- Official portal now owns province selection, regency/city selection, passcode validation, and result-table rendering.
- Enabled JavaScript, DOM storage, cookies, and third-party cookies for the official portal's web workflow.
- Added in-app Back and Reload controls.
- Removed the old duplicate province/regency dialog and Bearer-token form from the active UI.
- The passcode is entered on the official site and is not stored, logged, prefilled, or transmitted as an API token by AgriAttend.
- Cleared stale direct-API Verval summary data when opening the official portal, to avoid displaying failed/partial public data as a protected Verval result.
- App version: 1.6.7; Android versionCode 26.

Build verification:
- Pending GitHub Actions run for the 1.6.7 branch.

Not verified yet:
- Live SIMKOPDES route navigation from the Android WebView.
- Whether the current official route accepts WebView access on the target device/network.
- Passcode acceptance and full table display after user submission.
- Parsing official table rows back into the compact AgriAttend summary card; this is intentionally not guessed until a successful result page can be inspected.

Important:
- APK compilation does not prove passcode validation or live data retrieval. User-device testing is still required.
